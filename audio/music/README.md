# 《鲔》配乐（代码生成）

全片 485.19 s 的配乐全部由代码合成，不用任何采样。古琴是从零写的物理模型，其它声部是减法 / 加法合成。
所有卡点都从 `script/timeline.json` 推出（marks 与台词 lines，再加上 TTS 配音文件的发声检测），不写死秒数：配音或剪辑改了，重跑即可。

## 一条命令

```
.venv/bin/python audio/music/render.py
```

约 30 s（16 GB 内存的机器上），峰值内存约 2 GB。开跑前会看 `memory_pressure`，空闲低于 25% 就等。

输出（都在 `audio/out/`）：

| 文件 | 内容 |
|---|---|
| `music.wav` | 总混，485.192 s，48 kHz，24-bit 立体声，未母带，真峰值 ≤ -1.5 dBFS |
| `stems/music_<轨>.wav` | 6 个分轨：guqin / strings / hum / pad / glass / sub，同长同格式，相加严格等于总混 |
| `music_markers.json` | 主题三次完整出现 + 临终四音、两个硬切（含实测）、last_pulse 前的慢收、每个音乐卡点、段落 |
| `demo_guqin.wav` | 20 s 古琴独奏 demo（各种指法） |
| `music_qa/qa_report.json` | 质检报告（见下） |
| `music_qa/*.png` | 响度曲线、全片与分场频谱图、demo 频谱图与放大图 |

选项：`--out 目录`，`--cache 目录`（保留原始分轨缓存），`--from-cache`（只重做混音与质检），`--no-qa`，`--no-demo`。
作曲阶段在子进程里跑（`--stage compose`），跑完释放内存，混音与质检在父进程流式处理。

## 调式与律制

- D 羽调式五声：D F G A C。E、Bb 只作经过音与色彩（信标段、reveal 的假终止）。
- 三分损益律（五度相生），以 A4 = 440 Hz 为锚：A 与 1760 Hz 信标严格协和。相对十二平均律的偏差（音分）：A 0，E +1.96，D -1.96，G -3.91，C -5.87，F -7.82，Bb -9.78。所有声部共用 `mus_theme.hz()` 这一张律表。
- 古琴正调 C2 D2 F2 G2 A2 C3 D3 恰好就是 D 羽五声的音集，散音弦天然在调内，互相共鸣。

## 主题动机

`D3 A3 G3 F3 | D3`，第 5 个音回到主音。古琴指法：D3 七弦散音；A3 五弦七徽按音（绰入 + 吟）；G3 五弦走手下滑再勾；F3 三弦七徽按音（注入 + 吟）；D3 二弦七弦「撮」（D2 + D3 八度）。

## 硬切与静音

| 卡点 | 时间（s） | 做法 |
|---|---|---|
| dam_line | 153.048 | 门限：此前开始的所有声音连同混响尾巴在 10 ms 余弦里收到 0，切点起严格为 0，直到切点之后的新事件 |
| crash | 237.600 | 同上 |
| last_pulse 前 | 406.542 | 同一机制的慢收（550 ms）：405.842 左手按住全部琴弦止音，厅堂余响在 last_pulse 前 50 ms 收净 |
| black / 片尾 | 408.192 起、485.192 | black 时严格为 0；片尾 DUR-4.2 s 起余弦收到 0，最后 0.25 s 严格为 0 |

门限实现（`mus_core.Ctx.gate`）：每个事件按开始时刻归入「纪元」，渲染时每个纪元的总线（含卷积混响）只渲染到自己的切点，18 Hz 高通放在淡出之前，所以切点之后不留任何滤波器尾巴。

## 乐器配方

### 古琴（`mus_guqin.py`，数字波导物理模型）

一张琴 = 7 根弦 × 2 个振动偏振 = 14 个单环路波导，在一个 numba 内核里逐样本联合仿真。

- 弦：Karplus-Strong 的物理形式。环路延迟 = 往返一趟，三阶拉格朗日分数延迟逐样本读取，弦长可以连续变（按音、走手、吟猱绰注）。控制参数每 32 个采样更新一次，帧内延迟线性插值。
- 损耗：环路一阶低通，按基频处与 3 kHz 处两个 T60 设计。散音 T60 = 13·(65/f)^0.45 s，按音 9·(130/f)^0.5 s（指肉端吸收高频，按音更短更闷），3 kHz 处散音 1.5 s、按音 0.65 s。
- 刚性色散：环路里 2 节一阶全通，系数按弦长比例 p 数值拟合 B = B0/p²（弦越短越硬），B0 = 2.2–4.0e-5。
- 拨弦：平滑脉冲 -> 1/f 倾斜（泄漏积分）-> 指肉 / 指甲低通（指肉截止 2.2–5.4 kHz 随力度，指甲 4.5–9.5 kHz 另加 3 ms 刮擦噪声）-> 拨弦位置梳状 1 - z^(-βN)（拨弦点距岳山 0.094 倍弦长，按音越高 β 越大，音色越空）。力度到振幅 0.07 + 0.93·vel^1.6。
- 起音精确到样本：激励从离开岳山处注入，提前一个往返周期；泛音只提前 frac 个周期（左手触点会把第一个波前提前反射回来）。实测起音误差小于 0.4 ms。
- 右手接弦：拨之前 14 ms 手指压住拨弦点（κ 0.45 的阻尼散射结），同弦重复弹奏时旧振动先被压一下。
- 泛音（只留节点分音）：左手在徽位轻触 = 在环路内该位置放一个有损阻尼散射结（κ 0.55，接近弦的特性阻抗，吸收最多），持续约 6.5 个周期后离弦。实测七徽泛音奇次分音被压 50.7 dB，五徽泛音非 3 倍数分音被压 40.6 dB。
- 吟猱绰注与走手：音高曲线逐控制帧驱动弦长。吟 = 小幅慢颤，猱 = 大幅更慢，绰 = 从下方滑入，注 = 从上方滑入，上 / 下 = 走手换音；被下一个关键帧截断的颤音有 80 ms 渐出。
- 手指摩擦声：由按弦位置的变化速度求滑动速度，摩擦 = 频率等于速度 / 缠弦节距（0.40–0.55 mm）的脉冲串 + 气声，0.07% 直接进琴身，0.35% 注入弦里激起高次分音；吟猱的摩擦只有滑音的 8%；落指抬指（速度超过 2.5 m/s）不算滑。
- 散音共鸣与弦间拍频：7 根弦的垂直偏振经同一个岳山阻抗结耦合（能量守恒，必然稳定），没弹的弦会被激起；各弦有 ±2.2 音分的定弦误差，水平偏振比垂直偏振高 0.6–1.4 音分、耦合更弱、衰减更慢，产生缓慢拍频和先响后长的两段衰减。
- 琴身：岳山速度 -> 两组生成的琴身脉冲响应（垂直与水平偏振各一组）：直达 + 100–400 Hz 的主共振峰（外加 400 Hz–1.5 kHz 次共振）+ 木头高频短噪声尾巴，45 Hz 高通。
- 止音：抬指（75 ms 内 T60 0.05 s）、按住（T60 0.09–0.10 s + 轻触阻尼）、全弦止音 damp_all。
- 可用指法：note（勾挑、绰注吟猱、上下）、harm（泛音）、cuo（撮）、sweep（滚拂）、damp / damp_all。

自检（`mus_demo.analyze()`，写进 `qa_report.json` 的 `guqin_model_check`）：一弦散音 C2 基频误差 -0.63 音分，拟合 B = 2.98e-5（目标 4e-5），第 25 分音偏高 19 音分；按音音准误差都在 ±0.7 音分内；泛音分音压制见上。

### 低音弦乐（`mus_inst.strings`）

大提琴组（5 个声部）、低音提琴组（4 个）、独奏大提琴（2 张弓）。带限锯齿（BLEP）多声部失谐（每个声部另有 ±2 音分的慢漂移）-> 两级状态变量低通，截止频率随力度与包络走 -> 琴体共振峰 EQ（大提 190 / 520 Hz，低提 100 / 330 Hz）-> 带通弓噪。颤音在音头 0.3–0.8 s 之后才慢慢进来；连奏线条（cello_line）相邻音交叠并滑入。低于 G2 自动给低音提琴。比 movie4 的版本更暗（亮度上限 1.1–2.4 kHz）、更慢。

### 远处的无词哼唱（`mus_inst.hum`）

每个音 5 个声部：锯齿源（颤音 + 抖动）-> mm / oo 共振峰（可随时间渐变张口）-> 低通 + 气声。放在 6.5 s 混响的远总线上，干声只占 35%。滑音用 smoothstep，每个音前 0.12 s 开始、0.34 s 完成。

### Pad（`mus_inst.air_pad` / `warm_pad`）

air_pad：每个音 6 个分音，每个分音 3 个副本，各自 ±0.3–1.0 音分的随机失谐与 0.04–0.25 Hz 的慢起伏，拍动不规则、不成周期；外加以音高为中心的带通气声。warm_pad：失谐锯齿 + 两级低通 + 合唱，只在夜城用。

### 玻璃泛音（`mus_inst.glass_grain` + `mus_score.sparkles`）

只给电感视觉用。一粒 = 自由梁的 4 个非谐分音（1 : 2.756 : 5.404 : 8.933），高分音衰减更快；warm 版本去掉高分音、起音更软（卵的琥珀光）。时间是非齐次泊松过程（密度随画面变化），音高从五声高音区随机取并加 ±12 音分微偏，长短、强弱、声像都随机。没有规律的 ping 铺底：质检里三段粒子起音的自相关最大值都在 0.1 左右。

### Sub（`mus_inst.sub_tone` / `heart`）

极低正弦 + 少量二次谐波，可带呼吸起伏、音分弯曲曲线和缓慢拍动。船：D1 随船下压 60 音分；大坝之后：D1 带 0.22 Hz 拍动。heart 是音乐性的低频脉动（A1，lub + dub），不是拟音。

## 混音（`mus_core.py` 总线，`mus_mix.py`，`render.py`）

- 总线与混响（生成的卷积脉冲响应，T60）：qin_room 1.1 s，qin_hall 2.8 s，qin_far 4.6 s，hall 3.2 s，far 6.5 s，shimmer 4.0 s。古琴按段落选 room / hall / far，玻璃走 shimmer，sub 干声。
- 分轨基准增益（dB）：guqin +4，strings -5，hum -3，pad -4，glass -5，sub 0。
- 响度：全片最响的 3 s 短时响度归一到 -14 LUFS（BS.1770 K 加权），全片积分约 -24.6 LUFS，动态保留给画面。
- 限幅：由总混求增益曲线（1.5 ms 前瞻，80 ms 释放），同一条曲线乘到每个分轨，分轨之和仍严格等于总混。本次没有触发（真峰值 -2.88 dBFS）。
- 内存：分轨逐个流式渲染，float32，事件稀疏存储；作曲阶段峰值约 2.05 GB，混音质检阶段约 1.96 GB。

## 质检（`music_qa/qa_report.json`）

- 时长 485.192 s，23 289 216 个采样；真峰值 -2.88 dBFS（4 倍过采样）；0 个削波采样；直流偏移小于 3e-7（约 -130 dBFS）。
- 两个硬切：切点之后 15–100 ms 内最大电平 dam_line -176.9 dBFS、crash -240 dBFS（严格为 0），都在切点当刻就低于 -60 dBFS。
- 静音：last_pulse 到 black + 0.5 s 严格为 0；片尾最后 0.3 s 峰值 -115.6 dBFS，最后 0.25 s 严格为 0。
- 卡点起音误差：127 个卡点中 89 个起音清楚可测，误差中位数 0.25 ms、95 分位 0.77 ms。38 个被正在响的声音盖住（快速的滚拂、modern 的锁、片名泛音串、同弦滑音后重拨、慢起的弦乐），上升不足 8 dB 不报数。两处同弦重拨的 G3 被判晚 22–28 ms，是检测器被前面余音抬高基线所致，2 ms 帧包络上跳变就在卡点上。
- 咔哒扫描（8 kHz 以上 1 ms 能量突增、相邻采样跳变）：6 个分轨都是 0 处。
- 短循环：非静音的 2048 采样块做 MD5，全片没有完全相同的块。
- 对白：71 句台词，0 个古琴起音落在正在发声处，10 个落在句内换气缝；台词期间 200 Hz–4 kHz 的音乐电平比句前 1 s 中位数低 3.2 dB。
- 图：`loudness.png`（BS.1770 瞬时 0.4 s 与短时 3 s 曲线，标出主题、硬切、台词），`spec_full.png` 与 `spec_<场>.png`（分块对数频谱，省内存），`demo_guqin_spec.png` / `demo_guqin_zoom.png`（分音列、绰注吟猱的滑音轨迹、泛音只剩节点分音）。

## 已知不足

- 没有人耳听过。所有判断来自频谱、响度与客观检测。
- 古琴音色偏暗（demo 里 1 kHz 比 125 Hz 峰值低约 15 dB），真琴的按音可能更亮、更有木头的「嗒」。
- 一阶全通色散在高次分音上拉伸不够（拟合 B 约为目标的 75%）。
- 弦乐、哼唱、pad 仍是减法 / 加法合成，独奏大提琴近听会有合成感。
- 摩擦声是近似模型（脉冲串 + 噪声），没有真正的指弦接触力学。
- 主题第二次与 L22 交错（音符放在换气缝），完整度依赖配音的停顿位置。
- modern 段只有 1.6 s，急促的锁在频谱上互相遮盖。
